# BTD Visual Look material variants

Place only Born to Dig-owned material variants here. Do not copy or convert an entire
vendor material library. A variant should exist only when a specific Scene or Prefab needs
different surface, emission, transparency, or culling behavior from the source asset.

See `../Docs/BTD_VISUAL_STANDARD_V1.md` for the Lit/Simple Lit and DoubleSided rules.
