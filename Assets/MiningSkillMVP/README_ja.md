# Mining Skill MVP

Playすると自動で起動します。シーンへの追加操作は不要です。

- `BornToDig/VoxelRock`では実際に削った密度100ごとに1 Skill Pointを獲得
- 旧`ClickableVoxelRock`では実際に削除された2ボクセルごとに1 Skill Pointを獲得
- 左クリック長押しで現在の採掘間隔ごとに採掘
- Tabキーでスキル画面を開閉
- スキル画面のLEVEL UPボタンでSkill Pointを消費してMining Speedを強化
- スキル画面中はゲームを一時停止し、マウスカーソルを表示
- 初回コスト3 SP、以降はレベルごとに2 SP増加
- 最大レベル6、採掘間隔は0.48秒から最短0.16秒
- 音、破片、画面振動は未実装

このMVPは`Assets/MiningSkillMVP`から自動起動するため、シーンファイルへの追加はありません。
