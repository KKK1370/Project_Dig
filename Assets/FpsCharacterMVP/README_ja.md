# Born to Dig - FPSキャラクターMVP

このフォルダーはキャラクター専用です。既存の岩オブジェクト、岩スクリプト、耐久値、マテリアル、配置は変更しません。

## 作成方法

Unity上部メニューから次を実行します。

`Tools > Born to Dig > Create FPS Character Only`

既存の `Main Camera` をFPSキャラクターへ取り付け、現在の位置・向き・Cameraコンポーネント設定を引き継ぎます。

## 操作

- WASD / 矢印キー: 移動
- マウス: 視点
- Space: ジャンプ
- 左Shift: 走る
- 左クリック長押し: ツルハシを連続で振る
- Esc: マウスカーソルを解放

## 既存の岩との関係

ツルハシはクリック入力を奪わないため、岩が現在持っているクリック／レイキャスト破壊処理はそのまま動作します。

キャラクター側ではツルハシの表示と振りアニメーションだけを行います。音・破片・画面振動・ヒットストップはまだ入れていません。岩へダメージ値を書き込んだり、岩へコンポーネントを追加したり、設定を変更したりしません。

## 後からドワーフを追加

作成された `MVP_FPS_Player` の `Dwarf Visual Slot` に完成したドワーフPrefabまたはFBXを指定できます。FPS移動・カメラ・当たり判定・ツルハシは維持されます。
